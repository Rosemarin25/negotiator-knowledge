# Управление уступками

## Принципы

Уступка должна учитывать экономическую ценность,
интересы сторон и последствия для соглашения.

## Алгоритм

1. Подготовь перечень возможных уступок.
2. Оцени стоимость каждой для себя.
3. Определи её потенциальную ценность для оппонента.
4. Предлагай взаимный обмен условиями.
5. Фиксируй достигнутые договорённости.
6. Следи за совокупной стоимостью пакета.

## Пример

"Если мы увеличим срок контракта до двенадцати
месяцев, можем ли мы обсудить другую цену?"

## Ошибки

- Уступки без понимания пределов.
- Неясные взаимные обязательства.
- Игнорирование общей стоимости сделки.
- Согласие под неподтверждённым давлением сроков.

## Упражнение

Создай список из пяти возможных уступок.
Расположи их по стоимости для пользователя.
